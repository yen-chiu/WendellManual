# Folio 迁移待办与适用范围

## 构建依赖告警

2026-11-18 的 npm audit 报告发现 Picomatch 的正则拒绝服务告警，依赖链上多个包被连带标为 high。该报告中的条目数不代表不同漏洞数量。[上游公告 GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) 当时列出的受影响范围为 <=4.0.7，尚无修复版本。

本站以静态 HTML、CSS、JS 发布，线上不运行 Node 服务，也不接受访客提交的 glob 模式。构建仅处理仓库内既定路径。上述条件降低本部署方式的暴露面，并不表示依赖漏洞已经修复。保留告警，跟踪上游补丁，补丁发布后更新锁文件并回归构建和路径检查。

## 历史内容

旧 Jekyll / Just the Docs 的配置、导航和样式教程作为历史参考保存，不能直接用于 Folio。页面顶部有范围提示；后续若需要编写 Starlight 操作指南，应新增对应文档，不篡改旧教程的历史内容。

## 后续切换

Folio 首次上线只作为并行预览。旧站入口切换、旧站全量跳转、删除原库与自定义独立域名不属于本轮已执行事项。

此前博客的「整站设计与交互统一验收」仍是独立整改目标，迁移文档库不会把它自动标记为完成。


## 历史外观演示

旧主题的字体尺寸、颜色和布局工具类示例保留原文与代码，但没有逐项复刻整套 Just the Docs 样式。当前优先保证正文、代码、链接和主要图表可读；如需研究某个旧样式，可结合原站对照。


## Pages 源站证书开关

公开 https://yenchiu.com/folio/ 已通过浏览器和 HTTP 验证。GitHub Pages API 的 https_enforced 开关暂时无法启用，接口返回证书尚不存在；没有为此修改原域名、DNS 或证书配置。此项保留为后续基础设施核对，公开 HTTPS 可访问不等于该接口状态已经修复。

## 搜索引擎收录

当前为并行迁移预览，页面统一使用 noindex, follow；站内全文搜索正常。正式切换入口时再确定 canonical、收录与旧站跳转策略。
