# 404 改版方案：未印的一页
{: .no_toc }

2026-11-05。博客的 404 一直"可爱但不够贵"：紫渐变数字、刘看山线稿、十二行迷路诗，三样东西互相抢眼，主按钮还被挤到 838px 以下。这篇是同一次改版的完整判断——设计师做什么、架构师怎么落地、代价多少，以及一个能直接点开跑的原型。

---

## 一、结论

现在的 404 不是"不够花哨"，是**没有主张、也没有用**。

改版只做三件事，且都是替换而非叠加：

| 换掉 | 换成 | 为什么 |
| --- | --- | --- |
| 三个焦点 + 渐变字 | **一个叙事**：一页没被印出来的书，一盏跟着你走的灯 | 高级感来自"只有一个焦点，且它有理由" |
| 装饰性的诗 | **一句主张** + 朱红印章 | 文案是设计的一部分，不是填充 |
| 两个按钮 | **一个真能用的站内检索** + 三条安静出口 | 404 的第一职责是帮人找到东西 |

工作量：P0 半天上线，含埋点与回归约 1.5 天。

---

## 二、诊断（对着线上页面，逐条有据）

| # | 问题 | 证据（1280×900 线上截图） |
| --- | --- | --- |
| 1 | 视觉焦点打架 | 渐变 404 / 狐狸插画 / 十二行诗，三处都在抢第一眼 |
| 2 | 行动太晚 | "去往首页"出现在 y≈838px，1366×768 笔记本直接出屏 |
| 3 | 模板味 | `#6366f1→#a855f7→#ec4899` 渐变数字 + 大圆角药丸按钮，2021 年模板的标配 |
| 4 | 没有恢复路径 | 没搜索、没"你可能想找"；右栏"最近更新"是主题侧栏，不是内容策略 |
| 5 | 占位没清 | 面包屑还露着英文 `You seemed to be lost...`；诗靠 `white-space: pre-line` 硬撑 12 行 |
| 6 | 布局断裂 | 260px 插画 + 30rem 文字列，中间空 3rem，行尾频繁折行 |

判断：这是**信息结构**的问题，不是美化能解决的，值得整页重写。

**高级 404 只有三层：叙事、工艺、可用。** 绝大多数模板停在前两层。这个站三层素材都有：刘看山线稿、"读书，买花，长大"的调性、现成的站内搜索索引。所以方案走三层，不做粒子特效。

## 四、设计师视角

### 4.1 三个方向，先做减法

| 方向 | 一句话 | 成本 | 风险 | 适配度 |
| --- | --- | --- | --- | --- |
| **A. 未印的一页**（选它） | 深色书封上，灯照到哪里字才亮到哪里；找不到就用检索 | 低（纯 CSS/SVG） | 低 | ★★★★★ |
| B. 灯下找书 | 整页书架/书桌场景，灯光扫过书脊 | 高（要新画一套） | 与 Chirpy 白卡片打架 | ★★★ |
| C. 404 小游戏 | 狐狸跳坑，跳过去才回首页 | 高 | 包体、可访问性、维护 | ★★ |

### 4.2 概念

> 这一页，没有被印出来。
> 灯是你，书是这座站。照到哪里，字才亮到哪里。

"没印出来"比"走丢了"克制：不是我弄丢了你，是这一页本来就不存在。灯把 404 的"空"换成可探索的"暗"——动一下鼠标，页面才活。

### 4.3 视觉规范

| 类别 | 值 |
| --- | --- |
| 纸 / 炭 / 朱 | `#F2EDE4` / `#121216` / `#AD3A2D`（朱只给印章和状态点） |
| 灯 | `rgba(255,236,198,.2)`，全场唯一高光来源 |
| 数字 | Iowan Old Style → Palatino → Georgia，178px / 字距 .015em |
| 中文标题 | 25px / 500 / 字距 .055em / 行高 1.5 |
| 小字 | `ui-monospace` 10–11.5px / 字距 .08em |
| 圆角 / 描边 | 26px / 1px `rgba(255,255,255,.075)`（呼应站点 22px 卡片） |
| 动效 | `cubic-bezier(.2,.8,.25,1)`；入场 .9s，灯 1.25s，印章 .6s，结果 .34s / 45ms 交错 |

**三种材质细节**（廉价深色卡和高级深色卡就差在这）：

1. `feTurbulence` 颗粒 5% + `mix-blend-mode: overlay` —— 去塑料感。
2. 卡面顶边 1px 渐隐高光 —— 像覆膜印刷品的反光边。
3. 印章用 `feDisplacementMap` 位移 1.1 —— 边缘不齐，才像盖上去的。

### 4.4 交互

| 交互 | 行为 | 目的 |
| --- | --- | --- |
| 指针移动 | 灯跟随（rAF 节流），数字高光同步，横向位移 7px | 把"暗"变成可探索 |
| 首次进入 | 灯从左下扫到数字上，再交给指针 | 教会用户"这里能动" |
| 任意键 | 直接聚焦搜索并带上这个字 | 整页变成一个输入框 |
| ↑ ↓ / ↵ / esc | 键盘导航、打开、清空 | 无障碍 + 手感 |
| 点印章 | 查无此页 → 此书未完 → 去别处看，重盖一次 | 5 秒彩蛋，20 行代码 |

状态要补全：默认 / hover / focus-visible / 有结果 / 无结果 / 无 JS / `prefers-reduced-motion` / `hover:none`（触屏不做灯，给静态暖光）。

### 4.5 文案

- 角标：`ERROR 404 · NOT FOUND`
- 主标题：**这一页，没有被印出来。**
- 副标题：地址可能改过，也可能它只是草稿里的一句话。／先读一页再走 —— 灯还在。
- 路径回显：`你找的是 /posts/xxx`
- 检索占位：找一找 —— 标题、标签，或者你记得的那句话
- 空结果：没有找到「…」· 换个词，或者回首页看看

## 五、架构师视角

### 5.1 约束

- Jekyll + Chirpy gem，GitHub Pages 托管，Cloudflare 在前。
- 404 由 GitHub Pages 用 **HTTP 404 状态**返回 `/404.html`，别改成 200。
- 全站 CSS 已 150.5 KB，**不能**为低频页再往全局包里塞。
- 站内检索索引 `assets/js/data/search.json`：16 篇 / 101 KB，站内搜索页本来就会加载它。
- 现页面已把 CSS 内联在 `assets/404.html` 里，这个选择是对的，沿用。

### 5.2 预算

| 指标 | 目标 | 依据 |
| --- | --- | --- |
| 增量体积 | 原型 42.6 KB → **gzip 12.5 KB**；正式版（狐狸只留一份、去演示数据）≈ 8–9 KB | 实测 |
| 新增请求 | 0（索引按需拉，多半已被站内搜索缓存） | — |
| LCP | < 1.2s（纯文本首屏，无字体无图片） | — |
| CLS | 0 | — |
| 对比度 | 小字 5.8:1 / 4.6:1，过 WCAG AA | 深色卡最易翻车处 |

### 5.3 落地结构

```
assets/404.html                      ← 整页重写：结构 + 内联 <style> + 内联 <script>
assets/img/404/liukanshan_wire.svg   ← 不变，内联进页面（currentColor 染色）
_sass/ · _config.yml                 ← 不动
```

**为什么内联**：404 是低频页，150 KB 全站 CSS 已经很重；内联的 8 KB 只在这一页付钱，还省一次请求。将来要复用到别的错误页，再抽 `assets/css/404.scss`。

代码分三层，全部 IIFE、不挂 `window`、零依赖：

```
INDEX（索引缓存）→ search() → render()/move()   ← 纯函数，好测
Lamp（rAF + pointermove）                        ← 独立，可整体关闭
Seal / hotkeys / theme                           ← 独立小模块
```

### 5.4 关键决策

| 决策点 | 选择 | 理由 |
| --- | --- | --- |
| 索引加载 | 首次 focus/input 才 fetch，内存缓存，2s 超时降级 | 101 KB 不该为 99% 不搜索的人付 |
| 路径回显 | `pathEl.textContent = location.pathname` | 路径可被构造成 `/<img onerror>`，**绝不能 innerHTML** |
| 灯 | `pointermove` + rAF；`hover: none` 给静态光 | 触屏没有指针，动反而耗电 |
| 数字高光 | `background-clip: text` + CSS 变量坐标 | 一个元素搞定光斑，不用 canvas |
| 狐狸显形 | `mask-image` 径向渐变跟随灯 | 灯照到才现身，是叙事的一部分 |
| 印章质感 | 小元素 `feDisplacementMap` | 静态、面积小，成本可忽略 |
| 结果列表 | 内联展开（非绝对定位下拉） | 无遮挡、无 z-index 战争，移动端更稳 |

### 5.5 风险与兜底

| 风险 | 兜底 |
| --- | --- |
| 旧 Safari 不支持 `mask-image` | 底图保持 3% 透明度，仍可辨认，不报错 |
| `feDisplacementMap` 低端机掉帧 | 静态小元素；必要时 `@supports` 关掉，退回干净印章 |
| 索引 101 KB 首字延迟 | 首次 focus 预取 + 超时降级为纯链接 |
| Cloudflare 缓存了 404 响应 | 部署后确认 HTML 不被边缘缓存，必要时 purge |
| 移动端键盘弹起挤压卡面 | `min-height` 自适应 + 结果内联展开 |

### 5.6 验收清单

- [ ] Lighthouse 移动端：Performance ≥ 95，A11y = 100
- [ ] axe DevTools 零 issue
- [ ] 纯键盘走完：Tab → 输入 → ↑↓ → ↵ → esc
- [ ] 关掉 JS：四条链接仍可点，标题正常
- [ ] `prefers-reduced-motion` 下无扫灯、无位移
- [ ] 375 / 768 / 1280 三档无横向滚动
- [ ] 明暗两套主题对比度复测
- [ ] `/404.html?x=<script>` 不执行、不破坏版面
- [ ] 首页与文章页 CSS 体积无变化

### 5.7 排期

| 阶段 | 内容 | 工时 |
| --- | --- | --- |
| P0 | 重写 `assets/404.html`（结构 + 样式 + 内联前 20 篇） | 2–3h |
| P1 | 接 `search.json` 懒加载、键盘 / ARIA、双主题、回归截图 | 3–4h |
| P2（可选） | 印章彩蛋；404 命中日志（`navigator.sendBeacon` 打到现有 Worker，月度清死链） | 2h |

> P2 的日志很值：404 是最好的死链巡检数据源，记 `path + referrer`，每月看一眼，比任何 SEO 工具都准。
