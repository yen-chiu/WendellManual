# 2026-11-18 导航收敛、精选导读与分类整理

## 授权与范围

用户同意执行博客点评中的前三项：导航收敛、精选导读、分类整理。第四项整站设计与交互统一验收只备案为后续整改目标，见[后续整站验收目标](../design-consistency-roadmap/)。

实施对象为 yen-chiu-astro 的公开预览站。首页保留全屏封面与既有弹簧收起动画。聊天工作区和原 Jekyll 博客不参与本次调整。

## 导航与导读

- 手机顶栏保留明确的“博客”文字入口，以及搜索、外观、菜单。桌面主导航也提供直接进入博客的入口。
- 标签云、文件管理器、知识图谱集中到带文字和小图标的“探索”分组；阅读分组保留分类、标签与时光机。现有功能入口继续可用，点击后自动关闭菜单的逻辑保留。
- “进入博客”采用浅色实底，成为封面上更明确的主要入口。
- 封面下新增三篇人工精选：QQ 接入复盘、写作台 XSS 审计、异次元通讯网页版。每篇说明推荐理由，并保留原文章标题和链接。
- 首页提供少量导读；全部文章和分页仍放在博客页。精选文章若被删除或改了 slug，构建会明确报错，避免产生空卡片。

## 分类规则

分类在展示层集中映射，不移动原文、不改正文、文件标识或文章 slug。搜索索引、面包屑、目录页、文件管理器和图谱统一读取新的分类结果。

浏览器检查同时发现文件管理器把索引中的祖先分类当成直接归属，导致一级栏目把子目录文章重复列为“直接文章”。已按每个分类分支的最深路径判断直接归属，根栏目现在显示子目录，子目录显示对应文章；总文章数与直接文章数分别统计。

| 一级栏目 | 子分类 | 文章数 |
| --- | --- | --- |
| 建站笔记 | 性能优化、写作发布、部署配置 | 6 |
| 技术实践 | 工具与开发、服务部署、逆向与安全 | 7 |
| 生活记录 | 学习与日常、阅读观影 | 4 |

Blog、Blogging 合并为建站笔记；技术、Uncategories/Git 整理为技术实践；杂记中日常、学习和观影内容归入生活记录。杂记/折腾中的刷新按钮文章按实际主题归入建站笔记/写作发布。

为旧的 16 个分类路径生成静态跳转页。旧一级目录指向新的栏目概览，子目录指向对应子分类，使用一次跳转，避免形成跳转链。静态托管使用 HTML meta refresh，不能描述为服务端 HTTP 301。文章原地址保持不变。

52 个标签暂不合并：本轮批准的是分类整理，后续若合并标签，需要单独处理标签语义与旧地址兼容。
