## 架构审查与修改

- 项目站运行于 /yen-chiu-astro 子目录。Astro base 负责框架资产，构建后路径处理负责模板继承的根路径引用。
- JavaScript 使用 TypeScript AST 识别 URL 字符串和模板头，不直接对代码做全局正则替换；新增回归检查，覆盖正则、普通斜杠、外部 URL、重复前缀及动态文章地址。
- HTML 只处理 URL 属性、srcset 与脚本内容；JSON 解析后递归处理字符串，CSS 仅处理 url()。
- 独立 /search 页直接生成文章索引，支持标题、摘要、标签匹配，减少浮层不可用时对异步索引的依赖；浮层加载失败可重试并回退到独立页。
- 仍建议后续将源码所有内部 URL 统一通过 base-aware helper 输出，逐步替代部署时路径适配。当前适配层属于迁移兼容措施。

## 设计审查与修改

首页保持简洁文章列表，未自行确定最终品牌风格。移动端主要入口允许换行，文章标题行高、摘要宽度和日期层级更清晰；加入 hover、键盘 focus-visible 和减少动画支持。搜索页提供明确标签、结果数量与无结果提示。

## 仍需后续确认
