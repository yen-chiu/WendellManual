# 2026-11-18 手机界面信息密度与图谱交互优化

## 用户反馈

图谱下方节点检查区占用过多空间；筛选时画布已不可见，缩放、复位和操作提示却继续占据上方。用户要求以此为例优化整个 UI，而不是只修圈出的区域。

## 整体原则与范围

手机先显示内容与当前主要操作，节点连接数据、精细筛选、使用说明和归档辅助组件按需展开。保留至少 44px 的主要点击目标，不以缩小触控区换取空间。

- 图谱分成看图/筛选视图。筛选时隐藏整个画布工具区及所选节点栏，只保留筛选与返回/查看结果。
- 缩放/复位移入画布角落悬浮工具条，操作说明由问号入口展开；恢复默认筛选与复位视图分开，不再放重复的重置按钮。
- 未选节点时无详情面板；选中后先显示类型、单行名称和打开入口，连接数/入出链和完整名称放在原生 details 中。
- 图谱使用视口内 flex/grid，移动端画布优先占据剩余空间，不再把详情挤到大段页面滚动的最下方。ResizeObserver 处理筛选隐藏后显示、选中信息栏与视口变化，缩放状态在仅改变画布尺寸时保留。
- 博客、分类、标签、归档、文档、链接共用的手机页头压缩英文装饰标题、字号与留白；三张竖向统计卡变为一条三列统计栏，桌面样式保留。
- 博客的分类/标签/时光机入口在手机上改成一排三个紧凑入口，移除重复计数和装饰箭头。
- 归档“日历、数据与雨声”辅助区在手机默认折叠、桌面首次打开默认展开；主时间线更早出现，功能完整保留。

## 本地验收

390px 视口：未选节点画布高约 719.8px；选中后信息栏约 97.8px，画布仍约 614px。320px 视口选中后画布高约 510px，无横向溢出。展开连接详情能查看完整名称、连接数与入/出数据，收起后回到紧凑信息栏。

筛选时画布、缩放栏和所选信息完全隐藏；标签范围返回图谱为 52 节点/158 关系；恢复全部为原有 85/273。文档范围空结果时缩放栏隐藏。放大后 scale=1.3，显示选中栏/调整尺寸保留缩放。搜索建议自动返回图谱并选择节点。

验收发现原持久图谱弹层在跳到节点对应页面后可能仍保持 open，已增加 astro:before-swap 关闭。复测跳转 jekyll 标签页后 dialog.open=false，滚动锁关闭。

共享手机页头：博客/链接高约165px，归档/标签/分类约186px，统计横排。六个主要页面无横向溢出。归档辅助区手机默认收起、手动展开日历可用，1280px 桌面初次进入默认展开。

文档页检查发现残留 Iris 英文宣传和作者项目引流，改成本站中文文档入口、WendellManual 与迁移记录链接。手机博客文章工具栏也改成标题/布局按钮同行，去掉重复英文装饰。

[验收报告](https://github.com/yen-chiu/yen-chiu-astro/blob/main/migration/validation/ui-density-projects-qa.json)。完整构建136页、0类型错误/0类型警告/2既有提示；静态审计无缺失，17篇原文校验和路径/主题/图谱标签/日期回归通过。截图 .work/iris-graph-compact-mobile.jpg、iris-graph-compact-dark.jpg。真机和系统减少动效仍待设备验收；临时视口与外观已恢复。
