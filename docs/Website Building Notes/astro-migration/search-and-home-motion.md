# 2026-11-18 搜索面板与首页弹簧动效

## 用户反馈与原因

手机搜索筛选的白色边框包不住类型下拉框；空搜索框窄且背景透明；首项紫框和右侧圆点、红线含义不清。首页向上滑时头像、名字等消失生硬。

原搜索 CSS 有重复的移动端覆盖，筛选 max-height=200px 却堆叠三个字段且允许内容溢出；手机隐藏预览后仍被后续 !important 规则重新显示自绘匹配标记。首项紫框原本表示桌面当前预览，红线为预览位置、圆点为匹配标记。旧首页在进度超过0.6时直接隐藏整块介绍。

## 设计与实现

搜索改为原生 dialog：独立不透明面板、明确标题与关闭按钮、16px输入和足够对比度的提示。筛选默认收起，可显示启用数量，一键清除；下拉选项在文档流内展开，超长内容在筛选区滚动。结果区使用浏览器原生细滚动条，删除旧自绘缩略滚动条、圆点和红线。

手机不请求文章预览、不默认标注第一项；桌面两栏保留预览，并明确写“预览中”。方向键从首条开始，Tab保持原生焦点遍历，Enter仅在搜索输入框触发首条导航，不干扰筛选控件。关闭/跳转解除滚动锁。原生 dialog 保持在持久化导航栏内部，通过浏览器 top layer 展示，切页前关闭弹窗；避免将子节点移到 body 后再添加嵌套持久化标记所造成的层级冲突。

修正无关键词时筛选不触发、特殊正则字符高亮异常、快速查询与预览请求的旧结果覆盖。输入仍保留150ms去抖与原搜索索引。搜索结果和阅读全文使用明确导航，保留修饰键新窗口行为。

首页封面高度继续直接跟随页面位置；头像、眉题、名字、签名、入口按钮分别采用阻尼弹簧和错开的渐隐区间，伴随轻微向上移动、缩小及回弹。反向滑动连续恢复，完全透明后才隐藏和禁用交互。版权说明逐渐接替主视觉。RAF仅在运动未稳定时运行；离开页面清理，后台暂停，系统减少动态效果时跳过弹簧位移。增加根元素尺寸监听，避免搜索开关改变滚动条宽度后封面越界。

## 验证与边界

生产构建136页，0错误/0警告，2个既有提示；17篇原文SHA一致，57项persona引用无缺失。静态资源检查无缺失。原站根部署、聊天数据和文章正文未修改。

Chrome以320/390/1280px测试浅色/深色面板。390px筛选区底549px，类型展开底541px，均在面板底836px以内。手机无默认预览选中与自绘标记。测试“一”13条、“1”8条、“[”7条、空输入仅文章17条、技术标签6条及无结果提示；桌面预览与首条方向键正确，导航后可重新打开。最终复测首页→博客→搜索文章→首页，地址与内容同步，没有层级移动错误；首次按钮加载搜索后，跨页快捷键可用。冷启动尚未初始化时的键盘唤起未扩展，保留按钮入口。

首页收起终态340px，反向回到844px/头像透明度1。中途各层有不同透明度，未发生整块0.6阈值隐藏。弹簧辅助函数通过30/60/120fps收敛、反向和有界回弹检查。系统减少动态效果分支做源码检查，未修改操作系统偏好。未以实体手机验证输入法弹出、触摸手势与帧率。

验收数据：[search-motion-qa.json](https://github.com/yen-chiu/yen-chiu-astro/blob/main/migration/validation/search-motion-qa.json)。截图保存于本地 .work/iris-search-*.jpg 和 iris-hero-motion-partial.jpg。
