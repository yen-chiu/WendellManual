# 后续整改目标：整站设计与交互统一验收

备案日期：2026-11-18。状态：**已认可，待执行**。来源：博客点评第 4 项，用户明确要求纳入文档库作为后续目标。本轮导航、导读和分类调整不代表本目标已经完成。

## 目标

围绕“访客能轻松找到内容、读完内容”，系统检查全站的视觉与操作一致性。优先修复影响阅读、遮挡内容、无法关闭或难以操作的问题，再处理装饰细节。保留用户认可的全屏首页、透明头像、轻微倾斜回弹、名字故障动画与玻璃下拉导航。

## 待办与验收条件

| 优先级 | 范围 | 可核对的完成条件 |
| --- | --- | --- |
| P1 | 移动端排版与密度 | 检查 320、390、768、1280 CSS 像素宽度；无意外横向滚动、文字截断、控件越框或内容遮挡；标题、正文、辅助文字层级清楚 |
| P1 | 核心阅读链路 | 首页进入博客、精选进入文章、分类和标签筛选、搜索打开文章、文章返回列表均可用；子路径链接正确 |
| P1 | 弹层和导航 | 搜索、外观、标签云、文件管理器、图谱分别检查关闭按钮、Esc、点击空白与选中后的行为；模态层阻止背景误操作；焦点可进入并正确返回 |
| P1 | 触控与键盘 | 主要触控目标不小于 44×44；Tab 焦点清楚；按钮文字和图标含义一致；不依赖悬停才能使用 |
| P2 | 视觉规范 | 统一正文与标题字号、段落行距、卡片间距、圆角、边框、主次按钮；明确选中、悬停、禁用与键盘焦点状态 |
| P2 | 亮暗与调色 | 浅色、深色和跟随系统下检查主要页面；切换主题色后文字、占位提示、边框与激活态均可辨认 |
| P2 | 反馈和空状态 | 搜索无结果、目录无内容、图谱无匹配、图片或外部资源不可用时有简洁提示，不出现空白死区 |
| P2 | 动效与性能 | 首页收起和展开、头像反馈、菜单切换顺畅；开启减少动态效果时保留功能并减少动画；手机不因装饰动效明显卡顿 |

## 执行与留证

按首页、博客列表与文章、分类标签、归档、项目链接、关于与念真、各类工具弹层逐页检查。每个问题记录触发步骤、预期结果、实际结果、修复提交、测试视口与截图。

自动构建、静态链接及内容完整性检查作为发布前基础；真实浏览器交互、深浅主题和手机阅读体验需单独验收。工具不可用时明确写“未验证”，不能用源代码检查代替已通过的交互结论。

后续分批整改，每批完成备份、验证、预览发布和文档补录，再关闭对应待办。
