# 2026-11-17 浏览器恢复后发现的搜索路径回归

用户执行解锁 Windows、打开内置浏览器后，浏览器清单重新出现 Chrome 与 IAB，IAB 成功读取预览首页。点击搜索后操作调用超时，重连标签页也超时；后续清单显示该标签页已到独立搜索页，说明回退确实发生。

## 根因与修复

发布产物中的搜索索引请求使用 BASE_URL 加根路径，部署路径处理又给根路径加前缀，形成两次 /yen-chiu-astro。直接检查 dist/_astro/search.*.js 证实该表达式。搜索失败回退地址也有同类风险。

修复为统一调用 sitePath('contentIndex.json') 和 sitePath('search')，不再混用 BASE_URL 拼接与构建后替换。追加路径回归用例。

## 浏览器状态

此前“无浏览器访问”状态已经解除；页面读取成功。交互连接仍间歇超时，所以搜索浮层实际展开、手机图谱触屏与完整跨设备验收尚未通过。不能把连接恢复与网站功能验收混为一谈。
