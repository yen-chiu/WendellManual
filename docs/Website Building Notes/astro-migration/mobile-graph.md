# 2026-11-17 手机图谱可读性与五项验收续记

用户再次选择搜索、图谱、跨设备、文章展示和评论验收，并反馈手机图谱偏小。

## 本轮改动

- 手机优先展示图谱画布；筛选与设置默认折叠，可用标题栏按钮展开，保留 aria-expanded。
- 手机画布采用动态视口高度分配，避免控制面板占满首屏。
- 节点文字从固定 9px 改为手机 13px、桌面 11px。
- 节点透明命中区域手机半径至少 22px，不改变节点关系或数据。
- 画布下方新增放大、缩小与重置按钮，按钮最小 44px；设置输入保持 16px，减少手机聚焦时的意外缩放。
- 提示改为拖动画布、双指缩放与点击节点查看详情，详情链接仍用于打开文章。

完整构建 136 页通过；路径、双链、运行时路径回归通过；静态扫描内部链接与本地资源缺失 0。
