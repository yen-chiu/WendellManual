# 评论

评论用的是 giscus：把 GitHub Discussions 嵌进页面里。没有自建服务端。

## 读者怎么发

1. 文章拉到最底部，会看到评论区
2. 点「登录后发表评论」，用 GitHub 账号授权一次
3. 写内容、加表情，提交

提交的其实是一条 GitHub Discussion，所以：

- 要有 GitHub 账号。没有账号只能看，不能写
- 回复、编辑、删除，在 GitHub 上也都能操作
- 站点这边要删评论，去仓库的 Discussions 里删

## 为什么不用自建评论

自建要有服务端、要防垃圾、要备份、还要担心哪天挂掉。

Discussions 免费、稳定、数据在自己仓库里，对一个小博客足够了。
代价是门槛高了点——读者得先有 GitHub 账号。
