# 博客使用说明

这个博客不是现成的平台。文章是 Markdown 文件，评论存在 GitHub Discussions 里，
更新日志只是一个 YAML。好处是东西都在自己手上，坏处是——隔几个月回来，会忘了怎么用。

所以有了这一份说明。不按功能分，按「你要做一件什么事」分：

| 想做什么 | 去哪看 |
| --- | --- |
| 写一篇新文章 | [写作台](/WendellManual/docs/blog-guide/studio/) |
| 弄明白开头那段 YAML 写什么 | [Front Matter 字段](/WendellManual/docs/blog-guide/rules/front-matter/) |
| 读者怎么评论 | [评论](/WendellManual/docs/blog-guide/comments/) |
| 记一笔站点更新 | [更新日志](/WendellManual/docs/blog-guide/changelog/) |
| 站点和两个子站分别在哪儿 | [站点结构](/WendellManual/docs/blog-guide/structure/) |

先说一句最常踩的：**改完内容看不到新样式**，十有八九是浏览器缓存。
点页脚那个「刷新缓存」，或者直接打开 `/refresh/`，别急着怀疑部署。
