# 标点与预检查

## 中文标点会踩的坑

写分类时最容易打成全角逗号：

```yaml
categories: [杂技，综合]     # 错：这是「一个」分类
categories: [杂技, 综合]     # 对：两个分类
```

YAML 只认半角逗号。全角那一顿号不会被当成分隔符，于是整个「杂技，综合」变成一个分类名。

构建不报错，页面也正常，只是分类错了。等发现的时候，文章可能已经发了很久。

写作台里现在会把 `，`、`、`、`；` 先统一成半角再保存；
文章里手写的也会在保存前被检查出来。

## 日期在未来

站点配置了 `future: false`。日期比现在晚的文章不会被发布。

写完保存了却在首页找不到，先看日期。

## 推送前会自动检查

CI 里有一项 `Check post front matter`，会检查：

- front matter 是否存在、有没有闭合
- `title` / `date` 齐不齐，`date` 格式对不对
- 分类里有没有全角分隔符
- 图片路径指向的文件是不是真的存在（代码块里的示例会跳过）
- 文件名有没有日期前缀

本地也能先跑一遍：

```bash
node tools/check-frontmatter.mjs
```

它同时会检查更新日志那个 YAML。
