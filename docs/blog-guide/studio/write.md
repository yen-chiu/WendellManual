# 写一篇文章

## 新建

左上 `☰` 打开文章列表，右上角有「新建」。

新建之后可以什么都不填，先写正文。几个值得留意的：

- **日期是两个控件**：左边日期，右边时间。两个都必须有值，缺一个保存会被拦下。
- **日期不能在未来**。站点配置了 `future: false`，日期比今天晚的文章不会被发布。
  保存时会提醒，但如果硬存了，首页是看不到的。
- **标题**决定保存后的文件名。中文标题原样保留，英文会转成 slug。

## 正文

Markdown。工具栏从左到右：撤销、重做、H2、加粗、斜体、链接、行内代码、引用、列表、图片。

- 撤销 `Ctrl+Z`，重做 `Ctrl+Shift+Z` 或 `Ctrl+Y`
- 手机上工具栏可以横向滑动，右边还有几项

## 保存

右上角「保存」。默认直接提交到 `master`，1–2 分钟后站点更新。

底部有个复选框「提交到草稿分支 drafts」：

- 勾上 → 提交到 `drafts` 分支，线上不受影响
- 没写完的文章建议用这个，等想发了再改回不勾

## 改旧文

从文章列表点标题打开，改完照常保存。

「重载」是从 GitHub 重新拉一次，**会丢掉当前没保存的修改**。点之前想清楚。
